# 批注标准（annotation-rubric）

## 一、五色边界

高亮不是划重点，是**给论证结构上色**。一段里同一句话最多一种色。

| 色 | 只标什么 | 不标什么 |
| --- | --- | --- |
| 黄 论点 | 作者要读者相信的断言；摘要/引言的 thesis 句 | 方法描述、数据陈述 |
| 红 概念 | 首次定义的术语、指标名、损失函数名 | 普通名词、机构名 |
| 蓝 证据 | 样本量、CI、AUROC/F1/p、对比结果 | 泛泛的"表现良好" |
| 绿 让步 | 限制段、however 转折、先例支撑 | 纯递进转折 |
| 紫 方法 | 架构、训练配置、预处理、统计方法 | 结果解读 |

控制量：每段 3–6 处。超过 8 处说明在划重点，不在分析结构。

## 二、右栏三段式的写法

### 段落功能（4–6 字，动词开头）

好：结论先行 / 建立临床需求 / 预先消解金标准 / 形式化任务 / 让步与自我限定 / 收束与价值主张
坏：介绍背景 / 说明方法 / 总结（太泛，等于没说）

### 逻辑角色（一句话，回答"它在论证链里干什么"）

判据：把它删掉，论证会缺哪一环？删了不影响 → 这段不是论证段，是背景段，照实写"背景铺垫"。

### 技巧 / 漏洞（唯一有门槛的部分）

必须满足：**读者能拿着这句话回原文核对**。

合格：

- "差值 CI 下限 0.005，接近零；这是 p≈0.04 量级的边缘结果，却被表述为无保留的显著。"
- "'以其余评分者为金标准'测的是评分者间一致性，不是与病理真值的一致；论文全程用 performance 模糊了这一点。"
- "两套实验用了不同划分（420 张固定测试集 vs 70/10/20 随机划分），被并置陈述。"
- "条目从 First 直接跳到 Third，缺第二点；同段 'neither … were not permitted' 是双重否定。原文如此。"

不合格（空话，禁止）：

- "样本量可能偏小，值得进一步验证。"
- "该方法存在一定局限性。"
- "结果令人印象深刻。"

## 三、论证链审计清单（逐篇过，至少命中 3 条）

1. **摘要 vs 正文**：摘要的主张力量级，正文的证据撑得住吗？限定条件在摘要里出现了吗？
2. **金标准**：ground truth 是病理确诊、专家共识，还是"其余评分者的标注"？后者测的是 agreement。
3. **指标漂移**：两套实验之间换了指标（F1→AUROC）、换了划分、换了损失函数吗？
4. **显著性**：CI 下限离零多远？有没有做多重比较校正？
5. **样本**：测试集多大？单一机构？单一人群？单个设备？
6. **比较公平性**：基线是否同等调参、同等预训练、同等输入信息？
7. **选择性呈现**：图例是不是只放成功案例？失败案例在哪？
8. **相关工作**：只比排名，还是也比评价协议？
9. **可解释性**：热力图有定量评估（IoU、病灶框）吗？还是只有几张精选图？
10. **价值主张**：从技术指标跳到临床/社会价值时，中间少了哪一层证据？

## 四、译文的语体

- 意译优先：英文的被动与长从句拆成中文短句，不逐字对译
- 术语保留英文（AUROC、bootstrap、CAM），首次出现可加中文注释
- 数字、单位、置信区间原样保留
- 不加高亮、不加批注——译文块只负责"读懂"
- 读起来像中文学术论文，不像翻译腔：删"被进行""对于…而言"这类硬译
